# Logel AS – Tapt inntjening → Xref

Dette er en enkel nettside som viser tapt inntjening og snittprosent basert på registreringer fra Side 2.

## Publisering via GitHub Pages

1. Opprett et repository på GitHub, f.eks. `logel-xref`.
2. Last opp `index.html` og `README.md`.
3. Gå til **Settings → Pages**.
4. Under "Source", velg `main` branch og `/root`.
5. Trykk "Save".
6. GitHub genererer en URL, f.eks. `https://brukernavn.github.io/logel-xref/`.

## Bruk

Siden henter data fra `localStorage` som er lagret via Side 2. Sørg for at Side 2 er besøkt og registreringer er gjort før du åpner denne siden.
